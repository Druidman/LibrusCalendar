# LibrusCalendar

## What's that?
It's an portal.librus.pl scraper used to fetch lessons from timetable.
It puts this data then to a google calendar

## How to use it?
1. Follow this google api quickstart `https://developers.google.com/calendar/api/quickstart/python`
2. Insert `credentials.json` file in root folder of the project.
3. Install selenium: `pip install selenium`
3. Run main.py file
